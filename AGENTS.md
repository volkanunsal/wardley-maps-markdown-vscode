# AGENTS.md

Wardley Maps for Markdown — a VS Code extension that renders Wardley maps inline in the Markdown preview, from `owm`/`wardley` code fences.

## Setup

- Package manager: pnpm. Run `pnpm install` after cloning.
- Node 18+ (matches `target: "node18"` in `esbuild.config.js`).

## Common commands

- `pnpm run typecheck` — type-check with `tsc`, no emit.
- `pnpm run build` — bundle with esbuild.
- `pnpm run compile` — typecheck then build (also runs automatically as `vscode:prepublish`).
- `pnpm run watch` — esbuild in watch mode.
- `pnpm run test` — run the test suite (`node --test` over `test/*.test.ts` and `test/diagnostics/*.test.ts`).
- `pnpm run icons` — regenerate `media/icon.png` and `media/logo.png` from `media/logo-source.svg` via `rsvg-convert`.

Run `pnpm run compile` and `pnpm run test` before committing — both must pass.

To run a single test file: `pnpm exec node --test --import tsx test/<file>.test.ts`.

## Layout

- `src/` — extension source. `extension.ts` is the entry point; `markdownItPlugin.ts`, `renderer.ts`, `themeDetector.ts`, `zoomPan.ts`, `config.ts`, `previewScript.ts` implement the preview integration. `diagnostics/` holds the fence- and document-level diagnostic passes.
- `test/` — one test file per `src/` module, same basename, except `extension.ts` and `previewScript.ts`.
- `syntaxes/` — TextMate grammars: `source.owm` plus the Markdown fence-injection grammar.
- `media/` — `previewStyles.css`, `logo-source.svg` (hand-authored icon source), `icon.png`/`logo.png` (generated, committed), and `previewScript.js`/`.map` (generated by esbuild, gitignored — do not edit directly).
- `examples/` — sample Markdown files with `owm` fences, for manual verification.
- `scripts/generate-icons.sh` — regenerates the PNG icons from the SVG source.

## Conventions

- Commit messages: short, imperative. This repo does not enforce Conventional Commits.
- This extension never claims the `.owm`/`.wm` file extensions — `damonsk.vscode-wardley-maps` owns those. Do not add an `extensions` array to the `owm` language contribution in `package.json`.
- A change to `package.json`'s `contributes` block that affects user-visible behavior (grammars, languages, preview-script/style registration) needs a matching README update.
- This is a `vsce`-packaged extension — `dist/` and `media/previewScript.js`/`.map` are gitignored build outputs. `pnpm run compile` (runs automatically as `vscode:prepublish`) must run before `vsce package`.
